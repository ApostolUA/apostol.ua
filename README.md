# apostol.ua

Статичний сайт для GitHub Pages.

- `index.html` — тимчасово перенаправляє на /ca/toronto/
- `novyny.html` — головна зі стрічкою новин (повернути як index.html, коли з'являться інші новини)
- `ca/toronto/` — громада Торонто: проповідь Владики Браяна «Бог посилає вас»
- `CNAME` — домен apostol.ua

Нова громада: тека `<код країни>/<місто>/index.html`.
