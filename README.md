# apostol.ua

Статичний сайт для GitHub Pages: анонси й новини Української Греко-Католицької Церкви та громади.

Структура адрес: `apostol.ua/` — Україна (поки перенаправляє на /ca/), `/<країна>/` — стрічка країни з фільтром міст, `/<країна>/<місто>/` — стрічка міста, `/<країна>/<місто>/<матеріал>/` — окремий матеріал.

- `data/<країна>.json` — анонси (`events`) і новини (`news`); кожен запис має `sources` (посилання на джерела) і за можливості `poster`/`image`.
- `tools/build.py` — генерує `ca/index.html` і `ca/<місто>/index.html`. Після змін у даних: `python3 tools/build.py`.
- `ca/toronto/bog-posylaye-vas/` — проповідь Владики Браяна «Бог посилає вас».
- `ca/toronto/podii/` — старе посилання, перенаправляє на анонси Торонто.
- `novyny.html` — стара головна, у запасі.
- `CNAME` — домен apostol.ua.

Нове місто: додати його в `cities` у `data/ca.json` і запустити збирання.
